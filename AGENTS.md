- I have installed bend into `~/.bend`
- You can make it executable in the fish shell by running: `fish_add_path $HOME/.bend/bin`

When using Bend:
- run `bend guide` to learn it
- use `LAWS.bend` to keep important rules
- run `bend PROOF.bend` before committing
- parallelize the code whenever possible
- read `OPTIMIZING.md` before performance work — the levers are measured
- read `HOW-TO-USE-BEND.md` before porting anything — the checked artifact is the one that ships
